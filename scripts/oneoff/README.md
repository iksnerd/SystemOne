# One-off scripts

Run once, against data that no longer exists in the shape they expect, and kept only because they
record how something was produced. Nothing here is maintained and nothing here is on a path the
tests or the pipeline exercise.

- `import_pilot.py` turned the first pilot's ad-hoc files into a run directory.
- `make_probe_items.py` built throwaway training items for the Modal timing probe (FINDINGS §7).

The maintained tooling is one level up in `scripts/`.
